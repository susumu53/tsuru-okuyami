# 都留市 お悔やみハンドブック (Webアプリ ＆ デジタルガイド)

山梨県都留市のご遺族が、大切な方を亡くされた際の行政手続き・民間手続きを円滑かつ確実に行えるようサポートするインタラクティブなWebアプリケーションです。

---

## 🌟 主な特徴

1. **かんたん診断ナビゲーション（質問選択型）**
   - 故人の年齢、加入していた保険（都留市国保・後期高齢者等）、世帯主の有無などの簡単な質問に答えるだけで、「自分に必要な手続き」「持参する持ち物」「担当窓口」を自動で絞り込み表示します。

2. **都留市役所の公式窓口情報・電話番号を網羅**
   - 都留市役所（代表番号: `0554-43-1111`）の市民課（戸籍住民・国保・年金）、高齢者支援課（介護保険）、税務課（固定資産税・軽自動車税）、水道課等の受付窓口・内線番号を掲載。

3. **進捗状況のローカル自動保存**
   - ブラウザの LocalStorage を利用し、手続き完了のチェックボックス状態が自動保存されます。後日ブラウザを再度開いても進捗が維持されます。

4. **A4印刷 ＆ PDF出力完全対応 (`@media print`)**
   - 「印刷/PDF出力」ボタンを押すと、Webのナビゲーションやボタンを隠し、都留市役所にそのまま持参できるA4サイズの「お悔やみ手続きチェックシート」として印刷・保存が可能です。

5. **アクセシビリティ対応**
   - ワンタップで文字サイズを拡大できる「文字：標準 / 拡大」切替機能を搭載。高齢のご遺族でも読みやすいユニバーサルデザインを採用しています。

## 🚀 GitHub Pages での公開方法（無償Web公開手順）

本アプリはビルドツール不要の純粋な **HTML5 / Vanilla CSS / JavaScript (ES Modules)** で構築されているため、GitHubリポジトリにコミット・プッシュするだけで数分で公開可能です。

1. **リポジトリの設定を開く**
   - GitHubリポジトリページの **「Settings」** タブをクリックします。

2. **Pagesメニューを選択**
   - 左側のサイドメニューから **「Pages」** を選択します。

3. **ブランチとパスの指定**
   - **Build and deployment** > **Source** を `Deploy from a branch` に設定。
   - **Branch** に `main`（または `master`）を選択し、フォルダを `/(root)` に設定して **「Save」** ボタンを押します。

4. **URLの発行**
   - 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` に公開URLが生成され、誰でもスマートフォンやPCからアクセス可能になります。
