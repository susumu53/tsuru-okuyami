# 都留市 お悔やみハンドブック Webアプリ ＆ デジタルガイド 設計仕様書

**日付**: 2026-08-01  
**対象自治体**: 山梨県都留市  
**公開形式**: Webアプリケーション（シングルページアプリ） ＆ 印刷対応デジタルハンドブック (GitHub Pages対応)

---

## 1. 概要と目的

大切な方を亡くされた都留市民のご遺族が、煩雑で多岐にわたる死亡後の行政手続き・民間手続きを円滑かつ確実に行えるよう支援するインタラクティブWebハンドブック。

### 主な目標
1. **迷わせない導線**: ご遺族の状況（年齢・保険・資産等）に応じた「必要な手続き」と「持ち物」の自動診断・抽出。
2. **都留市役所の正確な情報連携**: 担当課、直通・代表電話番号（0554-43-1111）、庁舎所在地（山梨県都留市上谷一丁目1番1号）を網羅。
3. **紙・デジタルのハイブリッド対応**: 画面上での進捗チェック（LocalStorage保存）と、市役所に持参可能なA4印刷レイアウト（@media print）の両立。
4. **オープンソース・オープンデータ化**: GitHubリポジトリでコード管理し、GitHub Pagesで無償公開。他自治体への展開も容易な設計。

## 2. UI/UXデザインシステム

### 2.1 カラーパレット
- **プライマリ**: エメラルドセージ (`#2c6e49`) - 安心感と温かみ
- **セカンダリ**: セラミックネイビー (`#1a365d`) - 誠実さと信頼感
- **バックグラウンド**: ウォームホワイト (`#f8f9fa`)
- **サーフェス/カード**: 純白 (`#ffffff`) + 柔らかなシャドウ
- **アクセント**: 警告・期限＝アンバー (`#d97706`)、完了＝エメラルド (`#10b981`)

### 2.2 タイポグラフィ
- フォントスタック: `'Noto Sans JP', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- アクセシビリティ機能: フォントサイズ切替ボタン（標準 / 大）

### 2.3 閲覧モード
1. **Web閲覧・対話モード**:
   - ステップ型診断ナビゲーター
   - タブ切り替え（「簡単ナビ」「期限別」「カテゴリー別」「窓口案内」）
   - チェックリスト進捗保存（ブラウザのLocalStorageを利用）
2. **印刷・PDFモード (@media print)**:
   - Web用の操作要素（ボタン、フォーム、タブナビゲーション等）を非表示化。
   - A4サイズに最適化された段組とチェックボックスリストの印刷用レイアウト。

## 3. アプリケーション機能・構造仕様

### 3.1 タブ構成
- **簡単ナビ（診断ツール）**:
  - 質問項目: 故人の年齢 / 加入保険の種類 / 世帯主であったか / 車・不動産の所有 / 年金受給の有無
  - 診断結果として必要な手続き・持ち物・担当課を自動提示。
- **期限別ガイド**:
  - 7日以内 / 14日以内 / 1ヶ月〜年内 / 期限なし・中長期
- **カテゴリー別手続き一覧**:
  - 戸籍・住民票 / 国保・後期高齢者医療・葬祭費 / 年金 / 介護・福祉 / 税金 / インフラ・生活 / 民間・相続
- **都留市役所 窓口案内**:
  - 市民課、高齢者支援課、社会福祉課、税務課、水道課などの受付時間、電話番号、所在地情報。

### 3.2 都留市固有手続きデータ（収録対象）
1. **葬祭費の申請（国民健康保険・後期高齢者医療）**
   - 担当：市民課（0554-43-1111）
   - 給付要件：被保険者が死亡したとき、葬儀を行った者（喪主）に支給。
   - 持ち物：会葬礼状または領収書、喪主の振込口座確認書類、亡くなった方の保険証。
2. **国民健康保険・後期高齢者医療の資格喪失届**
   - 担当：市民課
   - 期限：14日以内
3. **介護保険被保険者証の返還**
   - 担当：高齢者支援課
   - 期限：14日以内
4. **未支給年金・遺族年金手続き**
   - 担当：市民課年金担当 / 大月年金事務所
5. **固定資産税 相続人代表者指定届**
   - 担当：税務課
6. **水道の使用開始・停止・名義変更**
   - 担当：水道課

   - スマートフォン（iOS/Android想定ビュー）およびデスクトップ表示の崩れ確認。

   - ブラウザ印刷プレビューにおけるA4レイアウトおよび不必要要素の非表示切り替えテスト。
