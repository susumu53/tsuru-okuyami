# 都留市 エンディングノート（終活ガイド）設計仕様書

**日付**: 2026-08-01  
**対象自治体**: 山梨県都留市  
**公開形式**: 「都留市 お悔やみ ＆ 終活ポータル」内統合Webアプリケーション (GitHub Pages対応)

---

## 1. 概要と目的

山梨県都留市にお住まいの市民が、人生の終末期や万が一の事態に備え、自分らしい意思やメッセージを安心して書き残せるデジタルのエンディングノート機能。

### 主な目標
1. **書けるところから少しずつ記入できるUI**: 5つの章（プロフィール、医療介護、葬儀、資産、メッセージ）をアコーディオン形式で提供。
2. **安心の完全ローカル保存**: 入力データは一切外部サーバーに送信されず、お使いのブラウザ（LocalStorage）にのみ保持される安全設計。
3. **都留市地域包括支援センターとの連携**: 相談窓口（いきいきプラザ都留 TEL: 0554-46-5114）の情報や相談タイミングを提示。
4. **美しいA4印刷・PDF出力**: 記入した内容を紙の冊子形式として印刷・家族共有できるレイアウト。

---

## 2. プライバシー ＆ 安全性の明示仕様

エンディングノートカードの最上部に、緑色の「🔒 個人情報保護・安全安心バナー」を常時表示します。

```text
🔒 【安心・安全に関するお知らせ】
本エンディングノートに入力されたお名前や医療・資産等のすべての情報は、
お使いのスマートフォン・パソコンのブラウザ内（LocalStorage）にのみ自動保存されます。
外部のサーバーや第三者にデータが送信されることは一切ありませんので、安心してお書きください。
```

---

## 3. 入力章構成 ＆ 収録フィールド

### 第1章：私自身のこと (Basic Profile)
- 氏名 / フリガナ / 生年月日 / 血液型 / 住所 / 本籍地
- 緊急連絡先①・②（氏名・続柄・電話番号・住所）

### 第2章：医療 ＆ 介護の希望 (Medical & Care)
- かかりつけ医（医療機関名・主治医・電話番号）
- 既往症・持病・アレルギー・常用薬メモ
- 介護の希望場所（自宅 / 施設 / 都留市内のデイサービス等）
- 病名告知・延命治療の意思表示（希望する / 希望しない / 家族に任せる）

### 第3章：葬儀 ＆ お墓の希望 (Funeral & Burial)
- 葬儀の希望（家族葬 / 一般葬 / 直葬など）
- 宗教・宗派 / 遺影写真の保管場所
- 火葬の希望（都留市火葬場「ゆうきゅうの丘つる」利用等）
- 納骨先・お墓の場所

### 第4章：財産 ＆ デジタル遺品の整理 (Assets & Digital)
- 主要な金融機関（銀行名・支店名 ※暗証番号不要の注意書き付き）
- 加入保険会社名
- 不動産・車両の所有有無
- スマホ・PCのデータ・サブスクの解約希望

### 第5章：大切な人へのメッセージ ＆ 保管場所 (Messages)
- 家族・親族へのメッセージ・感謝の言葉
- エンディングノートの保管場所
- 都留市地域包括支援センター（0554-46-5114）の案内

## 4. ファイル変更仕様

1. **`index.html`**:
   - ヘッダーのメインナビに「📝 エンディングノート」タブを追加。
   - `tab-endingnote` パネル（安全安心バナー、進捗ゲージ、5つの章アコーディオン、印刷/消去ボタン）を構築。
2. **`js/app.js`**:
   - `STORAGE_KEY_ENDING_NOTE`（`tsuru_ending_note_data`）を新設。
   - 全入力フォームの `input` / `change` イベントでリアルタイムLocalStorage保存。
   - ノートデータの読み込み・復元、進捗パーセンテージ計算、全消去処理の実装。
3. **`css/main.css` & `css/print.css`**:
   - エンディングノート用フォームスタイル、安心バナー、進捗ゲージの追加。
   - 印刷時にフォーム入力枠を「綺麗な印刷テキスト枠」として出力するA4メディアクエリ調整。
